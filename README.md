# Saksham Bhore - Professional Portfolio

This repository contains the professional portfolio of Saksham Bhore, built with React, Vite, and Tailwind CSS.

## Features
- **Modern UI**: Clean and professional design using Tailwind CSS.
- **Responsive**: Fully responsive across all devices.
- **Dynamic Content**: Component-based architecture for easy updates.

## Tech Stack
- **Frontend**: React.js
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React, React Icons
- **Build Tool**: Vite

## Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/engineershree/Saksham-Bhore.git
   ```
2. Navigate to the project directory:
   ```bash
   cd Saksham-Bhore
   ```
3. Install dependencies:
   ```bash
   npm install
   ```

### Development
To start the development server:
```bash
npm run dev
```

### Build
To build the project for production:
```bash
npm run build
```
